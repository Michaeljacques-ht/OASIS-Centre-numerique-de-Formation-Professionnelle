# Évaluation diagnostique

La carte « Devoirs et travaux pratiques de la formation » est remplacée dans l’éditeur par « Évaluation diagnostique — choisir une option ». Les devoirs et travaux de chaque module sont conservés. Les anciens travaux globaux et leurs copies restent enregistrés : leur suppression n’est pas effectuée.

Les options sont : QCM manuels, génération IA avec brouillon à vérifier, et import de fichier HTML autonome. La génération IA rassemble les leçons, ressources et compétences des modules et les objectifs de formation. Le formateur sélectionne les ressources à transmettre et précise les objectifs diagnostiques ; les limites de formats et de volume restent celles de la génération IA. Les questions visent les prérequis et le niveau initial, sans supposer que les leçons ont déjà été étudiées. L’IA ne publie pas sans validation. Pour un fichier HTML, appeler OASIS.submit(score,total) ; importer le fichier remplace les QCM diagnostiques. Retirer le fichier permet de revenir aux QCM.

À la première ouverture du lecteur, une évaluation diagnostique configurée est proposée avant les leçons. L’apprenant peut passer l’étape ; il retrouve ensuite le lien dans son parcours. Un résultat diagnostique est enregistré séparément (dernier résultat) ; il ne compte ni dans la note globale, ni dans les évaluations de module, ni dans la certification et ne bloque pas les modules selon la note obtenue. Le formateur consulte les résultats depuis la carte diagnostique. Une modification des questions ne recalcule pas les anciens résultats et ne force pas les apprenants ayant déjà passé ou ignoré le diagnostic à le refaire.

Les QCM sont corrigés sur le serveur. Le score d’un fichier HTML est transmis par le script du fichier ; il s’agit d’un positionnement non certificatif. Le fichier est exécuté dans un iframe isolé, avec un jeton de session et une validation du résultat côté serveur. Les appels IA réels et le rendu du HTML importé doivent être vérifiés après déploiement. Tests locaux : carte remplacée, questions manuelles, proposition avant les leçons, résultat séparé, régression du parcours et de la génération IA simulée.
