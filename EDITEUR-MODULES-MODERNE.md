# Éditeur des modules et ressources par leçon

La page de gestion de formation présente un en-tête bleu, les modules sous forme d’accordéons, une recherche par titre de module ou de leçon, un raccourci d’ajout et un panneau latéral masquable. Les informations de publication, couverture, barème, examen final et annonces restent accessibles dans le panneau. Les modules conservent leur ordre pédagogique ; aucun déplacement automatique n’est effectué.

Ouvrir un module puis une leçon pour consulter son contenu et gérer ses ressources. Les ajouts de fichiers et liens sont associés à cette leçon. Les paramètres d’une ressource permettent de changer la leçon associée. Les anciennes ressources sans leçon restent dans « Ressources communes existantes » et dans le lecteur de toutes les leçons du module jusqu’à leur affectation. Aucun fichier existant n’est supprimé ou affecté arbitrairement.

Le lecteur apprenant affiche les ressources de sa leçon et les ressources communes du module. La génération IA conserve l’accès à toutes les ressources du module pour construire son évaluation de fin de module.

Un seul bouton « Évaluation du module — choisir une option » ouvre les fonctionnalités existantes : consulter les questions, créer des QCM, importer une évaluation HTML ou générer un brouillon par IA. La validation du formateur, les scores et le déblocage linéaire restent inchangés.

La mise en page est inspirée du modèle fourni ; les chiffres et les états affichés proviennent de la formation réelle. Les tests fonctionnels vérifient le rendu HTML, l’association à une leçon, le filtrage des ressources côté apprenant et l’affectation des anciennes ressources. Vérifier le rendu dans le navigateur après déploiement.
