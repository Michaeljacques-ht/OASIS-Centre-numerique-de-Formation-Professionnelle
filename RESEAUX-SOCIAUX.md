# Liens du menu Suivez-nous

Dans les variables d’environnement de votre hébergement, renseignez les adresses HTTPS officielles souhaitées :

- OASIS_SOCIAL_FACEBOOK
- OASIS_SOCIAL_INSTAGRAM
- OASIS_SOCIAL_WHATSAPP (lien wa.me ou chaîne WhatsApp)
- OASIS_SOCIAL_X
- OASIS_SOCIAL_LINKEDIN
- OASIS_SOCIAL_YOUTUBE

Redémarrez le service après modification. Seuls les liens renseignés sont affichés. Sans lien configuré, le menu indique qu’ils seront disponibles prochainement.
